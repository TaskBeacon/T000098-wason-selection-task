# Wason 选择任务：条件规则检验的认知机制、内容效应与方法学边界

条件命题的检验要求个体区分能够支持规则的实例与能够推翻规则的反例。日常推理者是否会自发搜索反例，以及这种选择在多大程度上受逻辑形式、语言表述、既有知识和社会规范影响，是推理心理学的基本问题。Wason 选择任务（Wason selection task, WST），又称四卡片任务（four-card task），把这一问题转化为有限的证据选择：面对“如果 P，那么 Q”的规则，参与者须决定翻看 P、非 P、Q、非 Q 四类卡片中的哪些卡片。该任务同时提供明确的真值条件和高度稳定的内容效应，因而长期用于检验演绎推理、假设检验、匹配偏向及语用解释。不过，正确选择的心理含义取决于规则被理解为材料条件句、经验性概括还是义务规范；单次正确率也不等同于一般推理能力。对范式的使用需要同时保留逻辑基准与任务解释的条件性。

## 1. 范式提出与理论背景

Wason 于 1966 年在《New Horizons in Psychology》中提出选择任务，随后以“Reasoning about a rule”报告其标准化实验（Wason, 1966, 1968）。经典版本给出字母—数字双面卡片及一条条件规则。以“若一面是元音字母，则另一面是偶数”为例，P 卡必须翻看，以排除其背面为非 Q；非 Q 卡也必须翻看，以排除其背面为 P。非 P 卡不受规则约束，Q 卡背面无论为何都不能违反“P→Q”。因此，在材料蕴涵和“寻找足以判定违规的最小卡片集合”这一规范下，P 与非 Q 是正确集合。

早期研究发现，抽象题中常见反应是只选 P，或同时选择规则中明示的 P 与 Q，而非选择潜在反例非 Q。Wason 将这一模式联系于验证倾向；Johnson-Laird 与 Wason（1970）则把从初始匹配反应转向反例搜索描述为获得洞察的过程。否定词操控进一步表明，参与者倾向选择与规则表面命名相匹配的卡片，即使否定会改变这些卡片的逻辑角色；这一结果使“匹配偏向”成为比笼统确认偏误更贴近任务操作的解释（Evans & Lynch, 1973）。匹配反应反映注意和相关性分配，也可能与条件句语义表征共同作用，不能直接推断参与者持有普遍的求证人格倾向。

内容效应改变了范式的理论用途。主题化材料在部分研究中显著提高正确率（Wason & Shapiro, 1971），但一般的“具体化”并不稳定产生促进。Griggs 与 Cox（1982）的复现实验提示，能唤起既有经验中的违规实例或规则结构，才更可能改善表现。社会契约版本把规则表述为“获得利益 P 必须满足要求 Q”，此时检查 P 与非 Q 对应寻找违规获益者。Cosmides（1989）据此提出社会交换中的作弊者检测具有领域特异性。后续解释包括经验提取、许可图式、语用相关性和领域特异表征；Sperber、Cara 与 Girotto（1995）强调，参与者先推导语境中最相关且可检验的后果，再据此选卡。社会契约优势因此构成稳健的内容敏感现象，但其存在本身不足以在领域特异模块、一般语用过程和熟悉性解释之间作唯一裁决。

规范基准也经历了扩展。Oaksford 与 Chater（1994）把任务视为在稀有事件环境中最大化预期信息增益的归纳性资料选择，说明 P、Q 选择在某些先验分布下可能具有信息价值。这一分析揭示了实验指令的关键歧义：判断四张既定卡片是否违反普遍规则，与抽样检验一个不确定假设并非同一问题。近期基于准确性的统一分析仍认为，信息增益模型不能普遍把经典反应重新界定为规范正确（Vindrola & Crupi, 2024）。研究设计应预先说明目标是演绎判伪、概率性证据搜索还是义务违规检测，并据此确定正确答案和推论范围。

## 2. 任务逻辑、流程与核心测量

标准试次可分为规则编码、卡片评估和集合提交三个功能阶段。规则编码阶段建立 P 与 Q 的方向关系；卡片评估阶段分别判断翻看每张卡是否可能暴露 P∧非 Q；集合提交阶段整合各项判断。经典纸笔任务通常不设置严格时限、逐卡反馈或自适应程序，研究间在卡片是否真实翻开、是否允许反复尝试、题目数量和措辞上差异较大。计算机化版本可将规则、探测卡和反应阶段分离，以获得逐卡正确率和反应时，但这种改造同时改变了工作记忆、反馈学习和集合规划需求。

主要行为指标包括完整集合正确率、四类卡片各自的选择概率、反应类别和反应时。完整集合正确率直接对应预定规范，却会把“P 正确、非 Q 遗漏”与包含多个无关卡片的反应同记为错误。逐卡指标能够区分 P-only、P+Q 匹配、规范性 P+非 Q及其他集合，但四张卡的选择并非统计独立。Ragni、Kola 与 Johnson-Laird（2018）汇总 228 项实验后发现，真实选择集合较按单卡边际概率模拟的集合更具冗余性，支持以整体策略或心理模型解释反应。因而，不宜将四个二元选卡结果当作四次独立测量，也不宜只报告平均选卡数。

任务阶段对应的构念需要作有限解释。P 与 Q 的快速选择可反映规则中明示项目的匹配和相关性线索；非 Q 选择要求表征违反条件的反例，常涉及对条件方向的保持、否定加工与集合更新。P+非 Q 的最终集合支持参与者在该题表述下完成规范性反例搜索，但不能单独区分真值表推理、心理模型、熟悉规则提取或社会契约策略。反应时还混合阅读、逐卡评估、动作选择和复核过程；只有在这些阶段被实验设计分离时，才能把时长差异归于特定加工阶段。

## 3. 主要行为与神经科学证据

### 3.1 反例搜索、匹配偏向与个体差异

跨研究最稳定的行为事实是抽象版本中的非 Q 遗漏，以及义务性、社会契约或特定熟悉内容下的正确率提升（Cosmides, 1989; Ragni et al., 2018）。这些差异说明，同一形式逻辑结构不会保证相同的心理表征。否定成分、指令中的“真/假”或“违反”、卡片是否实际翻开，以及结果反馈都会改变相关性判断和学习机会。Nickerson、Butler 与 Barch（2021）让参与者实际翻开虚拟卡片，在多次作答中提供逐试次反馈和金钱激励，表现明显优于常见的假想翻牌程序；研究还显示规则措辞的误解能够促成单卡反应。这些结果限制了把经典低正确率归因于固定推理缺陷的结论。

个体差异证据同样依赖题型。Stanovich 与 West（1998）在三项、合计逾 800 人的研究中发现，非义务任务的正确解答与较高认知能力相关，而两个促进效应稳定的义务任务与认知能力关系较弱；不同题型的表现又并非完全无关。选择任务由此适合检验内容与认知能力的交互，却不宜以单个抽象题或社会契约题给个体贴上“理性/非理性”标签。多项目设计还需控制规则熟悉度、词频、否定形式和题目顺序，防止项目内容与目标构念混杂。

### 3.2 fMRI、EEG 与病损证据

任务特异的神经证据数量有限，且研究版本差异较大。Fiddick、Spampinato 与 Grafman（2005）在事件相关功能磁共振成像（functional magnetic resonance imaging, fMRI）研究中匹配社会契约与预防规则的逻辑结构和任务要求，观察到两类义务推理涉及不同的活动组合：社会契约相对更多涉及腹外侧、眶额和背内侧前额叶及左角回，预防规则相对更多涉及岛叶、扣带和豆状核等区域。该结果支持内容会调节推理时的网络参与，但样本规模有限，条件差异还包括语义、情绪和行动规范，不能据此确认独立的“作弊检测脑区”。单病例研究中，Stone 等（2002）报告双侧边缘系统损伤患者的社会交换推理选择性受损而预防推理保留；这种双重分离具有理论启发性，其病损范围和单病例性质限制了群体推广。

事件相关电位（event-related potential, ERP）研究提供了时间进程线索。Cutmore 等（2015）将规则与单张卡片判断分离，并加入训练和控制卡；负性卡片相对正性卡片表现出更大的 N2，较复杂的非 P、非 Q及 Q 条件伴随更持续的晚期加工。该模式与否定和关系复杂度增加相符，但改造后的逐卡判断并不等价于经典的同时四卡集合选择，N2 与晚期慢波也不能唯一定位为“逻辑推理”成分。近期 fMRI 研究同样采用序列探测版本，正确作答相对控制条件主要涉及额顶控制网络；其样本较小，且 P、非 P、Q、非 Q 的正确率不均，结果更适合说明任务控制需求，而非裁决双加工理论（Seyyed Hashemi et al., 2023）。现有 fMRI、ERP 与病损发现共同支持条件推理受内容表征、否定加工和控制需求影响，尚不足以建立可用于个体诊断的神经标志物。

## 4. 范式发展与主要应用

WST 的方法学发展沿两条方向推进。一类研究保持四卡形式，通过否定、主题内容、社会契约、预防规则和视角操控，检验规则表征如何改变证据搜索；另一类研究拆分选卡步骤、允许真实翻牌或重复反馈，以测量学习和逐项判断。前一方向有利于比较逻辑形式与语境，后一方向提高时序分辨率和行为信息量，但两者的结果不可直接互换。Kellen 与 Klauer（2020）对选择模型的争论也表明，模型拟合依赖反应分类、参数约束与关于选卡依赖性的假设；一个模型在集合频率上的优势不自动构成对其心理过程的唯一证明。

该范式已用于推理训练、教育、临床神经心理病例和人机推理比较。其核心优势在于可在保持 P→Q 结构时改变内容，从而检验抽象逻辑、经验知识与规范表征的交互。临床或发展研究若只发现某组在抽象题上正确率较低，仍需排除语言理解、工作记忆、教育经验和基线认知能力差异。训练研究则必须区分对特定题型的答案学习、对“寻找违规”指令的掌握与可迁移的反例搜索能力。重复呈现会暴露题目结构，因而前后测宜采用形式等价且内容不同的项目，并报告策略转变而不只报告总正确率。

## 5. 测量效度与解释边界

WST 具有清晰的操作效度：在明确的材料条件句和封闭四卡集合中，P∧非 Q 是唯一违规情形，P+非 Q集合具有可检验的规范依据。构念效度则受到条件句语义和任务目标制约。自然语言中的“如果”可表达因果、许可、义务或概率关系；参与者若把题目理解为寻找有信息的卡片、执行社会规范或验证有限样本，其选择未必对应实验者预设的材料蕴涵。抽象—社会契约差异也同时改变熟悉度、可想象性、行动者角色和违规显著性，不能简单命名为“纯逻辑能力差异”。

该任务最稳健的证据是群体水平的反应分布和内容效应，不是个体水平的稳定排序。现有代表性文献很少把经典四卡任务作为标准化心理测验报告内部一致性或重测信度；单题二元得分容易产生抽象条件地板效应和义务条件天花板效应。反馈和真实翻牌还能在短时间内改变策略（Nickerson et al., 2021）。用于个体差异研究时，应设置多个等价项目，保留逐卡选择与反应类别，预注册评分规则，并检验项目层级信度、重测效应和测量不变性。用于神经成像时，还需把规则阅读、逐卡判断和集合提交分离，避免把阅读或按键活动纳入目标对比。

因此，规范性 P+非 Q反应可作为特定规则表述下成功反例搜索的指标；P+Q 或 P-only 反应提示匹配、相关性或表征限制，但不能单独证明一般性确认偏误。群体差异可以支持某类内容或操作改变推理过程，不能直接转化为临床诊断、脑区因果机制或跨情境理性水平。

### 6.2 实现流程与关键参数

TaskBeacon 当前版本采用一个八试次区组，四个项目各出现两次，并按参与者特异种子随机排序。两个抽象项目分别使用元音—偶数和形状—颜色规则，两个社会契约项目使用借车—加油和饮酒—年龄规则；四张卡固定对应 P、非 P、Q、非 Q，正确集合均为第 1 与第 4 张卡。每试次先呈现 0.5 s 注视点，再进入选择阶段。数字键 1–4 将卡片加入无序集合，重复按键不会取消已选卡；每个选择步骤的等待上限为 30 s，最多记录五个动作阶段，Return 提交，选满四张时自动结束。提交后不呈现正误反馈，随后为 0.5 s 空屏试次间隔。主要结果包括完整集合正确率、四类单卡选择、P+Q 匹配、P-only、无选择及其他反应类别，并按抽象与社会契约条件汇总；总反应时为各选择步骤反应时之和。

**图 1. TaskBeacon 当前版本的试次流程与条件映射。** 抽象条件和社会契约条件均依次经历 500 ms 注视、卡片集合选择/提交和 500 ms 空屏间隔。规则上方同时呈现四张卡，位置依次对应 P、非 P、Q、非 Q；抽象示例为 A、D、4、7，社会契约示例为借用汽车、未借汽车、加满油箱、未加满油箱。参与者以数字键 1–4 逐张加入卡片，每个动作阶段最多等待 30 s，最多五个动作阶段，按 Return 提交；规范集合为 P 与非 Q（第 1、4 张），P+Q 和 P-only 分别单独分类。任务不提供试次反馈，也不采用难度或时限自适应算法；四类项目在八试次区组中等频随机呈现。

该实现适合比较抽象与社会契约内容下的集合正确率和错误类型。由于所有项目都保持 P、非 P、Q、非 Q 的固定位置，条件差异可能同时包含内容和位置学习；重复试次也可能促进规则结构学习。分析时宜分别报告首次暴露与后续试次，并把反应时解释为多步选择总时长，而非单一推理阶段潜伏期。
